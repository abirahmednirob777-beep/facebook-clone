# Facebook Clone

A Facebook-inspired social media front-end built with Next.js and Tailwind CSS.

## Features
- Responsive social feed layout
- Story cards
- Post composer
- Contact sidebar
- Mobile-friendly styling

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide icons
